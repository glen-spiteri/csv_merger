Pavlovia CSV Merger

Combine the one-file-per-participant CSVs from a Pavlovia download into a single spreadsheet. Everything runs in your browser; no data is uploaded anywhere.

Files are flagged when they have far fewer rows than most files (probably an incomplete run where the participant closed the tab) or when the participant ID looks like a test run. Flags are hints: decide using your own exclusion rules, and write down every file you drop and why. Untick a file to leave it out of the merged CSV. Columns are matched by name, so files with different columns still line up.
